## 2. Mathematical Formulations & Variable Definitions

### Phase 1: Coordinate Derotation & Centering

Before estimating planar alignment parameters, event coordinates are derotated into the reference frame using the filter rotation matrix and centered at the projected feature position[cite: 1].

$$
y_k^i = \pi \left( {}^{i^*}R_i \begin{pmatrix} \tilde{l}_k^i \\ 1 \end{pmatrix} \right) - \pi \left( {}^{i^*}R_i \begin{pmatrix} f(T_i) + u_i dt_i \\ 1 \end{pmatrix} \right)
$$

| Variable | Type / Dimension | Definition / Description |
| :--- | :--- | :--- |
| $y_k^i$ | $\mathbb{R}^2$ | Derotated and feature-centered coordinates of event $k$ in reference camera frame[cite: 1] |
| $\pi(\cdot)$ | Function | Perspective projection $\pi([X, Y, Z]^T) = \frac{1}{Z} [X, Y]^T$ to normalized coordinates[cite: 1] |
| ${}^{i^*}R_i$ | $\mathrm{SO}(3)$ | 3D rotation matrix from current pose ($T_i$) to reference pose ($T_{i^*}$) from EKF[cite: 1] |
| $\tilde{l}_k^i$ | $\mathbb{R}^2$ | 2D position of event $k$ forward-propagated to $T_{i+1}$ using local flow $u_i$[cite: 1] |
| $[\tilde{l}_k^i, 1]^T$ | $\mathbb{R}^3$ | Homogeneous image ray under a planar unit-depth assumption[cite: 1] |
| $f(T_i)$ | $\mathbb{R}^2$ | Tracked 2D feature position at time $T_i$[cite: 1] |
| $u_i$ | $\mathbb{R}^2$ | Average optical flow vector estimated in the first EM stage ($\text{EM}_1$)[cite: 1] |
| $dt_i$ | $\mathbb{R}^+$ | Duration of current temporal window: $dt_i = T_{i+1} - T_i$[cite: 1] |
| $f(T_i) + u_i dt_i$ | $\mathbb{R}^2$ | Predicted feature coordinate at $T_{i+1}$ prior to template alignment[cite: 1] |

---

### Phase 2: Alignment Cost Function (Scaled ICP)

Minimizes the soft-assigned Euclidean distance between transformed derotated events and the reference template[cite: 1]:

$$
\min_{\sigma, b} \sum_{k=1}^{n_i} \sum_{j=1}^{n_{i^*}} r_{kj} \left\| \sigma y_k^i - b - \tilde{l}_j^{i^*} \right\|^2
$$

| Variable | Type / Dimension | Definition / Description |
| :--- | :--- | :--- |
| $\sigma$ | $\mathbb{R}^+$ | 2D isotropic scale factor modeling scale change from depth variation[cite: 1] |
| $b$ | $\mathbb{R}^2$ | 2D translation offset representing accumulated lateral tracking drift[cite: 1] |
| $r_{kj}$ | $[0, 1]$ | Soft association probability (responsibility) linking event $k$ to template point $j$[cite: 1] |
| $\tilde{l}_j^{i^*}$ | $\mathbb{R}^2$ | 2D coordinates of point $j$ in reference template recorded at feature onset $T_{i^*}$[cite: 1] |
| $n_i$ | $\mathbb{N}$ | Number of events in current spatiotemporal window $W_i$[cite: 1] |
| $n_{i^*}$ | $\mathbb{N}$ | Number of points in reference template[cite: 1] |

---

### Phase 3: Expectation-Maximization ($\text{EM}_2$) Solution

#### E-Step: Soft Data Association
Computes normalized Gaussian likelihoods for candidate correspondences[cite: 1]:

$$
r_{kj} = \frac{\phi(y_k; \tilde{l}_j^{i^*}, \Sigma)}{\sum_{j'=1}^{n_{i^*}} \phi(y_k; \tilde{l}_{j'}^{i^*}, \Sigma)}
$$

* $\phi(x; \mu, \Sigma)$: Multivariate Gaussian density evaluated at $x$ with mean $\mu$ and covariance $\Sigma$[cite: 1].
* $\Sigma$: Measurement covariance matrix (configured as $2I$ in the benchmark implementation)[cite: 1].
* $j'$: Normalization summation index over all $n_{i^*}$ template points ensuring $\sum_j r_{kj} = 1$[cite: 1].

#### M-Step: Closed-Form Scale and Shift Updates
Computes centroids and updates parameters following scaled Iterative Closest Point[cite: 1]:

$$
\bar{y} = \frac{1}{n_i} \sum_{k=1}^{n_i} y_k, \quad \bar{l} = \frac{1}{n_{i^*}} \sum_{j=1}^{n_{i^*}} \tilde{l}_j
$$

$$
\sigma = \sqrt{\frac{\sum_{k=1}^{n_i} \sum_{j=1}^{n_{i^*}} r_{kj} (y_k - \bar{y})^T (\tilde{l}_j - \bar{l})}{\sum_{k=1}^{n_i} \sum_{j=1}^{n_{i^*}} r_{kj} (y_k - \bar{y})^T (y_k - \bar{y})}}
$$

$$
b = \frac{\sigma}{n_i} \sum_{k=1}^{n_i} y_k - \frac{1}{n_{i^*}} \sum_{k=1}^{n_i} \sum_{j=1}^{n_{i^*}} r_{kj} \tilde{l}_j
$$

---

### Phase 4: Feature Position Drift Update

Once $\text{EM}_2$ reaches convergence, the drift vector $b$ is subtracted while advancing the feature with the flow increment[cite: 1]:

$$
f \leftarrow f - b + dt_i u
$$

* $dt_i u$: Forward motion displacement predicted by short-term optical flow[cite: 1].
* $-b$: Translation drift correction derived from template registration[cite: 1].

---

### Phase 5: Gating & Two-Point RANSAC Outlier Rejection

#### 1. Mahalanobis Distance Gating
Pre-filters outlier event pairs prior to EM summation to reduce compute cost via k-d tree acceleration[cite: 1]:

$$
d = \sqrt{(x - \mu)^T \Sigma^{-1} (x - \mu)}
$$

* $d$: Mahalanobis distance metric (gated at a 4-pixel threshold in the paper)[cite: 1].
* $x$: Candidate transformed event point $(\sigma y_k - b)$[cite: 1].
* $\mu$: Template landmark coordinate $\tilde{l}_j^{i^*}$[cite: 1].

#### 2. Essential Matrix Formulation
Because relative rotation $R$ is known from the IMU/filter, only camera translation direction $t$ is unknown[cite: 1]. This parameterizes the Essential matrix using a **2-point correspondence hypothesis**[cite: 1]:

$$
E = [t]_\times R, \quad [t]_\times = \begin{pmatrix} 0 & -t_z & t_y \\ t_z & 0 & -t_x \\ -t_y & t_x & 0 \end{pmatrix}
$$

* $E \in \mathbb{R}^{3 \times 3}$: Epipolar Essential Matrix[cite: 1].
* $t \in \mathbb{R}^3$: Relative camera translation direction hypothesized by two correspondences[cite: 1].
* $R \in \mathrm{SO}(3)$: Relative rotation provided by the state filter[cite: 1].

#### 3. Sampson Epipolar Error Metric
Evaluates correspondence quality to identify and discard tracked outliers before the EKF update[cite: 1]:

$$
e = \frac{x_2^T E x_1}{(Ex_1)_1^2 + (Ex_1)_2^2 + (Ex_2)_1^2 + (Ex_2)_2^2}
$$

* $e$: First-order Sampson approximation of geometric epipolar distance[cite: 1].
* $x_1, x_2 \in \mathbb{R}^3$: Homogeneous normalized coordinates of feature correspondences across temporal frames ($[u, v, 1]^T$)[cite: 1].
* $(Ex_1)_m, (Ex_2)_m$: The $m$-th vector component of epipolar lines $Ex_1$ and $E^T x_2$[cite: 1].
